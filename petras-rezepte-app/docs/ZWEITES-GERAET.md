# Zweites Gerät (Notebook) verbinden

Voraussetzung: Auf dem ersten Gerät (PC) ist die Synchronisierung eingerichtet und Petra angemeldet
(siehe [SYNC-ANLEITUNG.md](SYNC-ANLEITUNG.md)).

1. **Am Notebook** die Setup-Datei `PetrasRezepteApp-Setup-2.0.0.exe` installieren (siehe [INSTALLATION.md](INSTALLATION.md)).
2. **Am PC**: Einstellungen → Geräte und Synchronisierung → **„Weiteres Gerät verbinden“** aufklappen →
   **Verbindungscode kopieren** (beginnt mit `PRA1-`). Den Code z. B. per E-Mail an sich selbst schicken.
   *Der Code enthält nur die Projektdaten – kein Passwort.*
3. **Am Notebook**: Einstellungen → Geräte und Synchronisierung → **„Ich habe einen Verbindungscode“** →
   Code einfügen → **Verbinden**.
4. **Anmelden** mit **derselben E-Mail-Adresse und demselben Passwort** wie am PC.
5. Nach wenigen Sekunden steht links **„Synchronisiert“** und alle Rezepte (mit Bildern, Favoriten, Notizen,
   Kategorien) sind da.
6. Optional: unter „Dieses Gerät“ → **Umbenennen** (z. B. „Petras Notebook“), damit man die Geräte unterscheiden kann.

Hatte das Notebook schon eigene Rezepte? Die bleiben erhalten und werden ebenfalls auf den PC übertragen
(doppelte Rezepte erkennt die App beim Import; Doppelte können einfach gelöscht werden).

## Gerät entfernen
Einstellungen → Geräte und Synchronisierung → Verbundene Geräte → **Entfernen**. Das entfernte Gerät meldet sich
beim nächsten Abgleich ab und erhält keine Änderungen mehr; seine Rezepte bleiben dort lokal erhalten.
Erneutes Anmelden verbindet es wieder.

## Abmelden
„Abmelden“ beendet die Synchronisierung auf diesem Gerät. Die Rezepte bleiben vollständig erhalten;
Änderungen werden nach dem nächsten Anmelden übertragen.
